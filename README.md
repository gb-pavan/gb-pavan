## 🚀 Projects

### Ed-Tech Examination Platform *(Education Platform)*

> **Stack:** Domain-Driven Design (DDD) · Vercel · RBAC · Server-based Authorization

Architected and implemented a production-grade EdTech system using a scalable and secure design with layered architecture. The platform enables educators to monetize premium exams while allowing students to securely access time-bound assessments through a controlled and role-safe system.

- Structured application using Domain Driven Design (DDD) architecture and deployed it to production using Vercel.
- Designed for high testability, extensibility and framework- and database-agnostic.
- Eliminated client-side role trust vulnerabilities by shifting critical permission logic to server, removing 100% of insecure exposure risks.
- Implemented RBAC with server-based authorization, reducing unauthorized access surface by ~80%.
- Minimized sensitive data leakage risk to near zero via strict error mapping and controlled API response policies.
- Enforced separation of concerns across domain, application, and infrastructure layers, improving long-term scalability.
